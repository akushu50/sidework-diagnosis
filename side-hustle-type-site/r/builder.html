WHY / 向いている理由

—手順とルールが決まっているものを、きっちり仕上げるのが得意

CAUTION / つまずきやすい点

FIRST STEPS / 最初の3手

1HTML / CSS を学び、既存サイトを1枚まるごと模写する
2架空の店舗のLPを1枚、デザインから作り切る
3制作会社の下請け案件か、知人の店のサイトから実績を作る
