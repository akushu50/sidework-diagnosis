バナー・ロゴ制作

DESIGNER
初収益まで 1〜3ヶ月

見た目を整える感覚が、そのまま単価になるタイプです。

WHY / 向いている理由

—色や余白の違いが気になる感覚は、それ自体がスキル

—バナー1枚3,000円から、小さく始めて実績を積める

—作ったものが目に見えて残り、そのまま営業材料になる

CAUTION / つまずきやすい点

修正依頼が何度も来る仕事。修正回数を最初に決めておくこと。

FIRST STEPS / 最初の3手

1Canvaか Figma を使って、既存のバナーを10枚模写する
2架空のバナー・ロゴを並べたポートフォリオを1枚作る
3ココナラなどで、相場より少し安く出品して初受注を取る
