# おすすめ副業診断テスト

12問の質問に答えると、8つの副業タイプからあなたに近いものを診断する静的サイトです。
ビルド不要・依存パッケージゼロで、GitHub Pages にそのまま置けます。

## 公開する手順

1. このフォルダの中身を GitHub リポジトリにプッシュします。
2. リポジトリの **Settings → Pages** を開き、Source を `Deploy from a branch`、
   Branch を `main` / `/ (root)` にして保存します。
3. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で公開されます。
4. 公開URLが決まったら、シェア画像を有効にするため次を実行してプッシュします。

   ```bash
   node tools/set-site-url.js https://ユーザー名.github.io/リポジトリ名
   ```

   これで `__SITE_URL__` が実際のURLに置き換わります。SNSのクローラーは
   相対パスを解決しないため、この一手間が必要です。

## ファイル構成

```
index.html            診断アプリ本体
assets/
  data.js             設問・タイプの定義（編集するのはここだけ）
  app.js              診断ロジックと画面描画
  style.css           スタイル
  char/*.webp         タイプ別キャラクター（8枚）
  ogp/*.png           タイプ別シェア画像 1200×630（9枚）
r/*.html              タイプ別の結果ページ。自動生成
tools/
  build-pages.js      r/*.html を生成
  set-site-url.js     公開URLを埋め込む
```

## 中身を変更したいとき

設問もタイプも `assets/data.js` にまとまっています。編集したあと、
結果ページを作り直してください。

```bash
node tools/build-pages.js
node tools/set-site-url.js https://ユーザー名.github.io/リポジトリ名
```

### 設問を足す・直す

`questions` に追加します。**選択肢の文章を先に書き、あとから点数を割り当ててください。**
軸から逆算して選択肢を作ると「どっち？と聞いているのに3択」「質問の前提を
否定する選択肢」といった不自然な文が生まれます。

点数は各軸 `-3〜3` が目安です。設問を増減してもスコアは自動で正規化されます。

### タイプを足す

`types` に1件足すだけです。`axes` の4つの値がそのタイプの座標になります。
キャラクター画像 `assets/char/<key>.webp` と、シェア画像
`assets/ogp/<key>.png`（1200×630）も同じ `key` で追加してください。

## 診断のしくみ

4つの軸で回答を採点し、各タイプの座標と比べていちばん近いものを選びます。

| 軸 | 意味 |
| --- | --- |
| social | ひとりで ↔ 人と関わる |
| stock | すぐ稼ぐ ↔ 積み上げる |
| creative | 数字・ロジック ↔ 感性・つくる |
| risk | 手堅く ↔ 試して直す |

回答の全パターン（3の12乗 = 531,441通り）を検証したうえで座標を調整しており、
8タイプへの振り分けは 11.3〜13.8%（均等なら12.5%）に収まっています。
どのタイプにも到達可能で、結果が出ないタイプはありません。
